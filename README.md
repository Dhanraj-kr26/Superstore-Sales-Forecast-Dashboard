# Super Store Sales Forecast Dashboard

## Objective
To analyze sales performance and forecast future sales trends using time series analysis.

## Tools Used
- Power BI
- DAX
- Power Query

## Features
- Sales Forecasting
- Time Series Analysis
- Interactive Dashboard
- State-wise Sales Analysis
- KPI Metrics
- Sales Trend Visualization

## Key Insights
- Identified monthly sales trends
- Forecasted future sales performance
- Analyzed regional sales distribution
